# mentalkentei

iOSアプリ「メンタルヘルス検定 合格予測（非公式）」の公開情報（サポート・プライバシーポリシー・利用規約）を管理するリポジトリです。GitHub Pages（`main` ブランチの `/docs`）で公開しています。

- サポート: https://taaaaho.github.io/mentalkentei/
- プライバシーポリシー: https://taaaaho.github.io/mentalkentei/privacy.html
- 利用規約: https://taaaaho.github.io/mentalkentei/terms.html

ページの文言は `scripts/build_pages.py` で管理しています。編集後に `python3 scripts/build_pages.py` を実行してください。

本アプリは個人開発の非公式アプリであり、大阪商工会議所その他の団体とは提携・協力・監修関係はありません。「メンタルヘルス・マネジメント」は大阪商工会議所の登録商標です。

ソースコードは非公開リポジトリ（`mentalkentei-code`）で管理しています。
